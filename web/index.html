ABOUT THIS SPACE

How AllMemory works

A short map of what you are looking at, and the guarantees behind it.

One tenant, one space

Every request resolves to a (tenant_id, agent_id) identity. Queries are always scoped to the tenant, so other spaces are never visible from here.

Read-only by design

This viewer only accepts a managed credential with the read scope. It cannot create, edit or delete memories, and the credential never leaves this tab.

Two interfaces

Agents use the REST API or the MCP server (Streamable HTTP and stdio). This browser is a third, human-facing window onto the same database.

Portable storage

SQLite is the default for a single host. Point DATABASE_URL at PostgreSQL to enable Alembic migrations and optional pgvector semantic search.

Memories keep their source agent, version and timestamps. Threads are scoped conversations; resolving a thread never rewrites a memory.
